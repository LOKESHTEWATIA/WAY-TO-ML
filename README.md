# ML Journey — 100 Days of Learning

Documenting a self-directed journey into Machine Learning and AI, built around CampusX's 100 Days of ML as the core curriculum, supplemented with Andrej Karpathy, 3Blue1Brown, Krish Naik, and DeepLearning.AI content where deeper intuition is needed.

Structure: 4 phases spanning ~7 months — math foundations (probability, statistics, linear algebra) → core ML → deep learning → applied projects.

Progress so far: Linear algebra (through eigenvalues/eigenvectors) and statistics/probability (distributions, hypothesis testing, chi-square, ANOVA) completed. Moving into core ML topics next.

What this repo tracks: notes, worked numericals, code implementations, and honest logs of what's understood vs. what's still shaky — not a highlight reel.
